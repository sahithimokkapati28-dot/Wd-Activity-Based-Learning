SimpleShop — Online Shopping Website
A simple, aesthetic, and responsive e-commerce website built using HTML and external CSS only. No JavaScript is used.
Features
- Responsive shopping navigation bar
- Promotional banner with a “Shop Now” link
- Product categories: Electronics, Fashion, Footwear, and Accessories
- Product cards with images and descriptions
- Current prices and original prices
- Discount labels
- Customer ratings
- “Add to Cart” buttons
- Responsive product grid for desktop, tablet, and mobile screens
- Clean white-and-blue design with rounded cards and soft shadows
Project Structure
Getting Started
1. Create a folder named shopping-website.
2. Save the HTML code as index.html.
3. Save the CSS code as style.css in the same folder.
4. Make sure the HTML file links to the external stylesheet:
5. 1. Open index.html in a web browser.
No installation or build tools are required.
Technologies Used
- HTML5 — page structure and content
- CSS3 — styling, product grid, hover effects, and responsive layout
Customization
- Update product names, descriptions, prices, discounts, and ratings in index.html.
- Replace the product image URLs with your preferred images.
- Change colors, spacing, typography, and card styles in style.css.
- Add or remove product cards by copying an existing .card block in index.html.
Notes
- Product images use external image URLs, so an internet connection may be needed to display them.
- The “Add to Cart” buttons are visual interface elements only. Shopping-cart functionality is not implemented because this project does not use JavaScript or a backend.
- The promotional and navigation links are placeholders and can be connected to real pages later.
